PRIME MUSCLE — GITHUB PAGES DEPLOYMENT

This package is ready to replace the current files in the GitHub repository that hosts primemuscle.in.

KEEP THESE FILES IN THE REPOSITORY ROOT:
- index.html
- style.css
- script.js
- CNAME
- sitemap.xml
- robots.txt
- logo.png
- abo.png
- h.png
- hr.png
- hero1.png
- c2.png
- c3.png
- c4.png
- c5.png

DEPLOY:
1. Back up the current repository.
2. Replace the old root files with the files in this package.
3. Commit and push to the branch used by GitHub Pages.
4. Do not delete CNAME — it keeps www.primemuscle.in connected.
5. GitHub Pages can take a few minutes to refresh.

IMPORTANT:
- No backend is required.
- Call, email, directions, social links, join modal, gallery lightbox,
  program slider, mobile navigation and mobile quick actions work with static GitHub Pages.
